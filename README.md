# Atlas

Atlas is a personal voice assistant built for natural, human-like conversation.
When users say the wake word, Atlas listens carefully, understands context, and
responds with thoughtful, concise answers.

## What Atlas does

- Listens for a wake word before actively engaging
- Supports natural conversation, including follow-up questions and casual chat
- Handles questions, commands, and creative requests with concise responses
- Runs fully locally to keep user data private
- Controls smart home devices such as lights and thermostats
- Aims to make users feel heard and understood through seamless interactions

## Product goals

Atlas should feel like talking to a trusted personal assistant:

- Private by default
- Context-aware
- Helpful without being verbose
- Capable across everyday tasks and smart home control
